# Concerts
This is a small personal app I use to track the concerts I'm visiting. It's main purposes are to track my concert visits (obviously), and to learn more/keep up with SwiftUI development.

Software development has changed dramatically with the rise of agentic AI, and my day job is no different. But the cost of this is you don't gain any (or as least not as much) experience about the technologies like in this case SwiftUI: you ask the AI to do something, you test it, maybe have a quick review of the code, and be done with it. SwiftUI is very complex with lots of pitfalls and oddities. So in this project, I'm deliberately writing nearly all of the code by hand. I might discuss with an AI to understand why something in SwiftUI isn't working, ways to solve it, and the like. But ultimately a major point of this project is me writing actual code by hand like in ancient times to better understand SwiftUI.
